# 如何二改悬浮窗样式

悬浮窗样式几乎都在 `runtime/src/main/java/amap/auto/patch/OverlayController.java`。二改 UI 时优先改这个文件，不要先改 smali。改完后重新运行 `patch.ps1`，脚本会重新编译 runtime 并注入 APK。

## 关键方法

- `buildPanel()`：创建主悬浮窗布局。
- `text(int sp, int color, boolean bold)`：创建文本控件。
- `buildLayoutParams(...)`：设置窗口类型、位置、宽高和 flags。
- `applyStyle(LinearLayout root)`：根据用户设置应用背景、边框、文字颜色和缩放。
- `buildSettingsView()`：长按后弹出的设置面板。
- `handleDrag(...)`：拖动悬浮窗并保存坐标。

## 当前主布局

当前悬浮窗是一个竖向 `LinearLayout`：

- `modeText`：分类标签，例如 `导航`、`红绿灯`。
- `primaryText`：主要信息，例如下一道路或 `绿灯 12s`。
- `secondaryText`：辅助信息，例如方向、灯组数量、距离。

当前 `modeText` 使用固定 `64dp x 22dp`，保证导航和红绿灯标签大小一致。主面板设置了最小宽高，避免文本刷新时窗口抖动。

## 修改尺寸

常见位置：

```java
root.setPadding(dp(10), dp(7), dp(10), dp(7));
root.setMinimumWidth(dp(184));
root.setMinimumHeight(dp(82));
modeText.setMinWidth(dp(64));
primaryText.setMinWidth(dp(160));
```

想让悬浮窗更宽，改 `root.setMinimumWidth` 和 `primaryText.setMinWidth`。想让标签更大，改 `modeText` 的 layout params：

```java
root.addView(modeText, new LinearLayout.LayoutParams(dp(72), dp(24)));
```

## 修改字体

字体大小在 `buildPanel()` 创建文本时指定：

```java
modeText = text(12, Color.WHITE, true);
primaryText = text(18, Color.WHITE, true);
secondaryText = text(12, 0xFFE2E8F0, false);
```

`text(...)` 内部设置了 `setIncludeFontPadding(false)`，这会让文字垂直空间更紧凑。如果中文显示被裁切，可以改回 `true` 或增加控件高度。

## 修改颜色和背景

`applyStyle(...)` 里有三套样式：

- `style == 0`：经典。
- `style == 1`：卡片。
- `style == 2`：紧凑。

背景由 `roundRect(color, radius, strokeColor)` 创建：

```java
root.setBackground(roundRect(0xEE111827, dp(8), 0xFFFACC15));
```

颜色是 ARGB 十六进制。`0xEE111827` 中 `EE` 是透明度，后六位是 RGB。

## 修改设置面板

设置面板在 `buildSettingsView()`。当前按钮包括：

- 启用 / 禁用
- 样式：经典
- 样式：卡片
- 样式：紧凑
- 大小 -
- 大小 +
- 关闭设置

新增按钮可参考：

```java
root.addView(button("按钮文字", new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        // 修改 SharedPreferences 或调用刷新逻辑
    }
}));
```

新增设置值时，在文件顶部增加 `KEY_...` 常量，并用 `prefs.get...` / `prefs.edit().put...` 读取保存。

## 修改窗口层级和触摸行为

`buildLayoutParams(...)` 会尽量复用高德原悬浮窗的 `WindowManager.LayoutParams.type`，这样可以沿用原窗口权限和层级。不要随意改成 `TYPE_APPLICATION_OVERLAY`，否则在改包高德内可能出现权限或层级差异。

flags 当前为：

```java
FLAG_NOT_FOCUSABLE
FLAG_NOT_TOUCH_MODAL
FLAG_LAYOUT_IN_SCREEN
FLAG_LAYOUT_NO_LIMITS
```

如果希望悬浮窗不接收触摸，需要加入 `FLAG_NOT_TOUCHABLE`，但这样会失去拖动和长按设置能力。

## 二改后验证

优先用测试壳验证 UI：

```powershell
.\build-test-apk.ps1
adb -s emulator-5554 install -r -t .\dist\amap_auto_patch_vm_test.apk
adb -s emulator-5554 shell appops set amap.auto.patch.test SYSTEM_ALERT_WINDOW allow
adb -s emulator-5554 shell monkey -p amap.auto.patch.test -c android.intent.category.LAUNCHER 1
```

确认文字不裁切、不同字段长度不会导致窗口抖动，再构造真实 APK。
