# 如何二改显示信息

当前整合版显示信息主要由 `companion/src/main/java/com/autonavi/companion/OverlayService.java` 负责接收、缓存、轮播和渲染；红绿灯 wrapper 由 `PatchBridge.onTrafficLightWrapper(...)` 转成 extras 后交给 `OverlayService`。旧版最小 runtime 的 `DataModel.java` / `OverlayController.java` 只适合测试壳或历史实现参考。

## 数据和分类

`OverlayService` 直接维护导航、红绿灯、巡航、车道、电子眼、TMC 等缓存字段，并根据当前缓存和过期时间决定渲染哪些区块。修改显示信息时优先搜索这些关键词：

```text
trafficLight
lane
edog
tmc
cruise
nav
render
```

如果要恢复巡航显示，重点检查 `OverlayService` 中控制导航/红绿灯/巡航区块可见性和轮播的逻辑，不要再改旧版 `DataModel.CATEGORY_CRUISE`。

## 修改轮播时间

当前每 3 秒切换一次：

```java
private static final long SLOT_MS = 3000L;
```

改成 5 秒：

```java
private static final long SLOT_MS = 5000L;
```

数据超过 `STALE_MS` 会被认为过期，不再显示：

```java
private static final long STALE_MS = 30000L;
```

## 修改导航显示

导航广播在 `OverlayService` 的广播处理逻辑中解析。搜索 `KEY_TYPE`、`NEXT_ROAD_NAME`、`SEG_REMAIN_DIS` 可以定位相关代码。

如果要显示下一道路和剩余距离，可优先使用：

- `NEXT_ROAD_NAME`：下一道路名。
- `SEG_REMAIN_DIS`：当前导航段剩余距离，单位米。
- `ROUTE_REMAIN_DIS`：全路径剩余距离，单位米。
- `SEG_REMAIN_DIS_AUTO`：转换后的当前导航段剩余距离，通常带单位。
- `ROUTE_REMAIN_DIS_AUTO`：转换后的全路径剩余距离，通常带单位。

## 修改红绿灯显示

红绿灯有两个来源：

- 广播：`OverlayService` 中处理 `KEY_TRAFFIC_LIGHT` 或包含 `trafficLightStatus`、`redLightCountDownSeconds`、`lightsData` 的分支。
- 内部 wrapper：`PatchBridge.wrapperToExtras(...)`。

实际改版高德主要依赖内部 wrapper。当前 wrapper 字段按观察结果读取：

- wrapper 字段 `a`：红绿灯列表。
- item 字段 `d`：状态。
- item 字段 `e`：倒计时秒数。
- item 字段 `c`：方向。
- item 字段 `a`：等待数量。
- item 字段 `f`：显示类型。

状态文本由 `lightText(...)` 决定：

```java
status == 1 -> 即将绿灯
status == 2 -> 绿灯
status == 3 -> 黄灯
status == 4 -> 即将红灯
```

方向文本由 `directionText(...)` 决定：

```java
1 -> 左转
2 -> 右转
3 -> 掉头
4 -> 直行
```

如果实车发现方向值不同，优先改 `directionText(...)`。

## 选择哪个红绿灯

`PatchBridge.wrapperToExtras(...)` 会遍历高德内部灯组并生成 `lightsData`。`OverlayService` 再解析 `lightsData` 并选择/渲染有效灯组：

- 秒数大于 0 加分。
- 状态大于 0 加分。
- 秒数在 4 到 10 之间额外加分。

如果要固定优先直行，可以在评分里增加：

```java
if (dir != null && dir.intValue() == 4) {
    score += 3;
}
```

## 新增一个显示字段

例如要在副行显示当前速度：

1. 在 `OverlayService` 对应广播处理分支读取 extra。
2. 写入对应缓存字段。
3. 在对应 render/update 方法里把字段显示到 TextView 或插件渲染模型。

## 新增一个分类

1. 在 `OverlayService` 里识别新的 `KEY_TYPE` 或 extra 字段。
2. 增加对应缓存字段和 `updatedAt` 时间戳。
3. 在显示策略里判断是否过期、是否参与轮播。
4. 在布局 XML 或 Java 创建对应 TextView/容器。
5. 在 render/update 方法里填充内容。

## 调试未知广播

对于暂不认识的广播，可以在 `OverlayService` 的广播入口临时输出 extras：

```java
Log.i("AmapCompanion", "extras=" + extras);
```

也可以用 adb 主动回放：

```powershell
adb shell am broadcast -a AUTONAVI_STANDARD_BROADCAST_SEND --ei KEY_TYPE 10001 --es NEXT_ROAD_NAME "人民路" --ei SEG_REMAIN_DIS 320
```
