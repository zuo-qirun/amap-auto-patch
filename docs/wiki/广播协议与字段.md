# 广播协议与字段

本页整理本项目用到的高德车机版标准广播能力，重点是让二改者知道每个广播和 extra 字段能驱动什么显示。内容按项目实际使用整理，不上传原 PDF，也不要求二改者先阅读 PDF。

## 广播方向

高德向外透出状态时使用：

```text
Action: AUTONAVI_STANDARD_BROADCAST_SEND
```

外部向高德请求或控制时通常使用：

```text
Action: AUTONAVI_STANDARD_BROADCAST_RECV
```

本项目运行在高德 APK 内，主要监听 `AUTONAVI_STANDARD_BROADCAST_SEND`。

## 3.3 引导信息透出

引导信息由高德主动发送，当前项目把它作为导航信息来源。

```text
Action: AUTONAVI_STANDARD_BROADCAST_SEND
KEY_TYPE: 10001
```

extra 字段：

| extra | 类型 | 含义 | 可用于悬浮窗 |
| --- | --- | --- | --- |
| `TYPE` | int | 导航类型，0 GPS 导航，1 模拟导航，2 巡航 | 判断当前模式 |
| `CUR_ROAD_NAME` | String | 当前道路名称 | 显示当前道路 |
| `NEXT_ROAD_NAME` | String | 下一道路名称 | 主行显示下一道路 |
| `SAPA_DIST` | int | 距离最近服务区距离，单位米 | 服务区提醒 |
| `SAPA_TYPE` | int | 服务区类型，0 高速服务区，1 其他服务区 | 服务区类型 |
| `CAMERA_DIST` | int | 距离最近电子眼距离，单位米 | 电子眼提醒 |
| `CAMERA_TYPE` | int | 电子眼类型 | 电子眼图标或文字 |
| `CAMERA_SPEED` | int | 电子眼限速，0 表示不限速，单位 km/h | 限速显示 |
| `CAMERA_INDEX` | int | 下一个电子眼编号，-1 表示没有电子眼 | 判断是否显示电子眼 |
| `ICON` | int | 导航转向图标 | 转向图标 |
| `NEW_ICON` | int | 新版导航转向图标 | 转向图标 |
| `ROUTE_REMAIN_DIS` | int | 路径剩余距离，单位米 | 全程剩余距离 |
| `ROUTE_REMAIN_TIME` | int | 路径剩余时间，单位秒 | 全程剩余时间 |
| `SEG_REMAIN_DIS` | int | 当前导航段剩余距离，单位米 | 到下一动作距离 |
| `SEG_REMAIN_TIME` | int | 当前导航段剩余时间，单位秒 | 到下一动作时间 |
| `CAR_DIRECTION` | int | 自车方向，正北为 0，顺时针增加，单位度 | 指南针或车头方向 |
| `CAR_LATITUDE` | double | 自车纬度 | 位置调试 |
| `CAR_LONGITUDE` | double | 自车经度 | 位置调试 |
| `LIMITED_SPEED` | int | 当前道路限速，单位 km/h | 限速显示 |
| `CUR_SEG_NUM` | int | 当前自车所在 link，从 0 开始 | 路径调试 |
| `CUR_POINT_NUM` | int | 当前位置前一个形状点号，从 0 开始 | 路径调试 |
| `ROUNG_ABOUT_NUM` | int | 环岛出口序号，只有部分转向图标有效 | 环岛出口 |
| `ROUND_ALL_NUM` | int | 环岛出口个数 | 环岛出口总数 |
| `ROUTE_ALL_DIS` | int | 路径总距离，单位米 | 全程总距离 |
| `ROUTE_ALL_TIME` | int | 路径总时间，单位秒 | 全程总时间 |
| `CUR_SPEED` | int | 当前车速，单位 km/h | 车速显示 |
| `TRAFFIC_LIGHT_NUM` | int | 红绿灯个数 | 导航路线上信号灯数量 |
| `SAPA_NUM` | int | 服务区个数 | 服务区数量 |
| `SAPA_NAME` | String | 下一个服务区名称 | 服务区名称 |
| `ROAD_TYPE` | int | 当前道路类型 | 道路类型 |
| `ROUTE_REMAIN_TIME_STRING` | String | 转换后的路径剩余时间，带单位 | 直接显示时间 |
| `NEXT_NEXT_ROAD_NAME` | String | 下下个道路名称 | 预告下一下一路口 |
| `NEXT_NEXT_TURN_ICON` | int | 下下个路口转向图标 | 预告图标 |
| `NEXT_SEG_REMAIN_DIS` | int | 距离下下个路口剩余距离，单位米 | 二级预告距离 |

| `ROUTE_REMAIN_TIME_AUTO` | String | 转换后的路径剩余时间，带单位 | 推荐直接显示 |
| `SAPA_DIST_AUTO` | String | 转换后的最近服务区距离，带单位 | 推荐直接显示 |

当前代码在 `DataModel.fromBroadcast(...)` 中优先读取：

```text
NEXT_ROAD_NAME
NEXT_ROAD
ROUTE_ROAD_NAME
ROAD_NAME
EXTRA_ROAD_NAME
roadName
SEG_REMAIN_DIS
ROUTE_REMAIN_DIS
NEXT_ROAD_DISTANCE
EXTRA_DISTANCE
distance
```

如果要让显示更稳定，建议优先使用 `SEG_REMAIN_DIS_AUTO`、`ROUTE_REMAIN_DIS_AUTO` 这类带单位字段；没有时再回退到 int 米数。

## 请求最后一次引导信息

高德可通过请求返回最后一次引导信息。当前项目运行在高德内部，通常不需要主动请求，因为高德会主动发送 `KEY_TYPE=10001`。

```text
Action: AUTONAVI_STANDARD_BROADCAST_RECV
KEY_TYPE: 10062
```

如果后续改成外部伴随应用模式，可以在应用启动时发送这个请求，让高德补发最近一次导航信息。

## 车道信息

```text
Action: AUTONAVI_STANDARD_BROADCAST_SEND
KEY_TYPE: 13012
```

extra 字段：

| extra | 类型 | 含义 |
| --- | --- | --- |
| `EXTRA_DRIVE_WAY` | String | 车道线 JSON 字符串 |

`EXTRA_DRIVE_WAY` 内常见字段：

| JSON 字段 | 含义 |
| --- | --- |
| `drive_way_enabled` | 车道线是否有效 |
| `drive_way_size` | 车道数 |
| `drive_way_info` | 车道数组 |
| `drive_way_number` | 车道编号，从左到右 |
| `drive_way_lane_Back_icon` | 车道图标编号 |

当前项目把车道归到巡航分类缓存中，但默认不显示。如果要显示车道，需要在 `DataModel` 单独建立车道分类，或把它加入导航副行。

## 高德前后台状态

```text
Action: AUTONAVI_STANDARD_BROADCAST_SEND
KEY_TYPE: 10019
```

extra 字段：

| extra | 类型 | 含义 |
| --- | --- | --- |
| `EXTRA_STATE` | int | 运行状态 |

当前代码识别：

- `EXTRA_STATE=3`：显示为 `高德前台`。
- `EXTRA_STATE=4`：显示为 `高德后台`。
- 其他值：显示为 `高德状态`。

当前前后台状态不会进入轮播分类，只用于确认广播可接收。若要根据前后台隐藏悬浮窗，可在 `DataModel.fromBroadcast(...)` 给它单独分类，并在 `OverlayController.update(...)` 中处理。

## 巡航信息

当前项目对巡航采用兼容识别：只要 `KEY_TYPE=60021`，或 extra 中出现 `CUR_SPEED`、`SPEED`、`LIMITED_SPEED`、`CAMERA_SPEED`，就按巡航处理。

常用 extra：

| extra | 类型 | 含义 |
| --- | --- | --- |
| `ROAD_NAME` | String | 当前道路 |
| `EXTRA_ROAD_NAME` | String | 当前道路 |
| `CURRENT_ROAD_NAME` | String | 当前道路 |
| `CUR_SPEED` | int | 当前车速 |
| `SPEED` | int | 当前车速 |
| `LIMITED_SPEED` | int | 当前限速 |
| `CAMERA_SPEED` | int | 电子眼限速 |

当前代码会缓存巡航信息，但 `DISPLAY_ORDER` 不包含巡航，所以不会显示。恢复显示方法见 [[如何二改显示信息]]。

## 红绿灯信息

本项目支持广播红绿灯字段，也支持高德内部 wrapper。实测中红绿灯主要依赖内部 wrapper。

广播兼容字段：

| extra | 类型 | 含义 |
| --- | --- | --- |
| `trafficLightStatus` | int | 信号灯状态 |
| `EXTRA_TRAFFICLIGHTSTATUS` | int | 信号灯状态 |
| `LIGHT_STATUS` | int | 信号灯状态 |
| `status` | int | 信号灯状态 |
| `redLightCountDownSeconds` | int | 倒计时秒数 |
| `EXTRA_REDLIGHTCOUNTDOWNSECONDS` | int | 倒计时秒数 |
| `COUNTDOWN` | int | 倒计时秒数 |
| `countDown` | int | 倒计时秒数 |
| `dir` | int | 方向 |
| `direction` | int | 方向 |
| `lightsCount` | int | 灯组数量 |
| `trafficLightNum` | int | 灯组数量 |
| `lightsData` | String | 灯组数据，具体结构依版本而定 |

当前状态映射：

| 状态值 | 显示 |
| --- | --- |
| 1 | 即将绿灯 |
| 2 | 绿灯 |
| 3 | 黄灯 |
| 4 | 即将红灯 |
| 其他 | 信号灯 |

当前方向映射：

| 方向值 | 显示 |
| --- | --- |
| 1 | 左转 |
| 2 | 右转 |
| 3 | 掉头 |
| 4 | 直行 |

内部 wrapper 读取字段：

| 对象 | 字段 | 含义 |
| --- | --- | --- |
| wrapper | `a` | 红绿灯列表 |
| item | `d` | 状态 |
| item | `e` | 倒计时秒数 |
| item | `c` | 方向 |
| item | `a` | 等待数量 |
| item | `f` | 显示类型 |

如果适配新版本后字段名变化，优先修改 `DataModel.fromTrafficLightWrapper(...)`。

## adb 回放示例

导航：

```powershell
adb shell am broadcast -a AUTONAVI_STANDARD_BROADCAST_SEND --ei KEY_TYPE 10001 --es NEXT_ROAD_NAME "人民路" --ei SEG_REMAIN_DIS 320
```

红绿灯：

```powershell
adb shell am broadcast -a AUTONAVI_STANDARD_BROADCAST_SEND --ei KEY_TYPE 60073 --ei trafficLightStatus 2 --ei redLightCountDownSeconds 12 --ei dir 4 --ei lightsCount 3
```

前后台状态：

```powershell
adb shell am broadcast -a AUTONAVI_STANDARD_BROADCAST_SEND --ei KEY_TYPE 10019 --ei EXTRA_STATE 3
```

巡航：

```powershell
adb shell am broadcast -a AUTONAVI_STANDARD_BROADCAST_SEND --ei KEY_TYPE 60021 --es ROAD_NAME "中山路" --ei CUR_SPEED 42 --ei LIMITED_SPEED 60
```
